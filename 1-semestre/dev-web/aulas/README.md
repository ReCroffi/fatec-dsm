## Estrutura

Cada aula é uma pasta com seu próprio `index.html` e, quando tem estilo, o
`styles.css` ao lado. Imagens compartilhadas entre as aulas ficam em
`assets/imagens/`.

```
Web/
├── assets/imagens/
├── aula02-primeiro-site/
│   └── index.html
├── aula03-semantica/
│   ├── index.html
│   └── styles.css
├── aula04-listas-links/
│   └── index.html
└── aula05-css/
    ├── index.html
    └── styles.css
```
